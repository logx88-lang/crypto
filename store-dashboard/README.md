# 가게 매입·매출 대시보드

배달앱 정산서, 세무사 매입매출장, 신용카드·통장 내역 엑셀을 한 폴더에 넣고 변환하면
매출(채널별)·배달앱 수수료·매입(항목별)·카드·통장을 한 화면에서 보는 HTML 대시보드가 만들어집니다.

> 실제 장부 데이터는 저장소에 올리지 않습니다. `data/`, `dist/`, 엑셀 파일은 `.gitignore` 로 제외돼 있습니다.

## 사용법

```bash
pip install pandas openpyxl msoffcrypto-tool
mkdir -p store-dashboard/data   # 여기에 엑셀 파일을 모두 넣기
python3 store-dashboard/build_data.py store-dashboard/data --password <배민 파일 암호>
# → store-dashboard/dist/dashboard.html 을 브라우저로 열기
```

## 자동으로 알아보는 파일

| 파일 | 판별 기준 | 쓰는 곳 |
|---|---|---|
| 배달의민족 정산명세서 (월별, 암호) | `상세` 시트의 "정산 상세내역" | 배민 매출·수수료·입금액 (주문일 기준) |
| 쿠팡이츠 부가세 신고자료 (`merchant_sales_report…`) | `매출인식 시점`, `Store ID` 열 | 쿠팡 주문 단위 매출·환불·요일/시간 패턴 |
| 요기요 주문내역 | `상호명`·`주문번호`·`주문중개이용료` 열 | 요기요 매출·차감비용 |
| 세무사 매입매출장 | `매출`·`매입` 시트 | 홈택스 카드·현금영수증 매출, 모든 매입 |
| 신용카드 이용내역 (매출일/승인일 두 양식) | `가맹점명`·`승인번호` 열 | 카드 사용처, 장부 미반영분 |
| 사업자 통장 거래내역 (엑셀 또는 CSV, EUC-KR 자동 처리) | 거래일·입금·출금·잔액 열 | 입출금 분류, 매출 입금 대사, 장부에 없는 비용(인건비 등) |

통장 내역은 변환 때 넣어도 되고, 만들어진 대시보드의 **통장** 탭에서 엑셀을 직접 올려도 됩니다
(브라우저에만 저장).

## 계산 기준

- 금액은 모두 부가세 포함.
- **매출 기준 토글**
  - 플랫폼 정산서(기본): 배민·쿠팡·요기요는 각 정산 원자료, 홀은 홈택스 카드매출 + (홈택스 현금영수증 − 쿠팡 현금결제분).
  - 세무사 장부: 배민·요기요 정산서가 장부보다 많은 부분을 홈택스 현금영수증에 이미 포함된 것으로 보고 홀 현금영수증에서 뺌.
- **비용** = 매입장 + 장부에 없는 카드 사용분 + 통장의 인건비·세금·4대보험.
  생활비로 분류한 항목, 차량 등 자산 구입은 제외. 재료 계좌이체는 세금계산서와 겹쳐서 통장에서 다시 더하지 않음.
- 통장 출금 중 세무사 장부의 거래처와 이름이 겹치는 것은 이미 매입장에 있다고 보고 비용에 다시 더하지 않음.
  카드대금·부가세 납부·대표자 인출·가족 자금·자산 구입도 비용에서 제외.
- 사람 이름(직원, 대표자, 가족)처럼 가게마다 다른 통장 규칙은 데이터 폴더의 `rules.json` 에 둔다
  (저장소에는 올라가지 않음):

  ```json
  {"bank": [["^홍길동$", "인건비"], ["^김사장$", "사장 인출"], ["^박납품$", "식자재", "장부"]]}
  ```
  세 번째 값 `"장부"` 는 세무사 장부에 이미 있는 거래라는 뜻.
- 거래처·적요별 항목 분류는 `template.html` 의 `RULES`, `BANK_*` 규칙과 `rules.json` 으로 자동 지정되고,
  화면에서 바꾼 분류는 브라우저에 저장됩니다.
