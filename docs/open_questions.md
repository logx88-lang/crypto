# 확인 질문 목록 (구현 착수 전 답변 필요)

> 설계서(`docs/design.md`)의 미확정 지점. 일부는 **오프라인 PC에서 직접 확인**해야 한다.
> 답변해 주시면 설계에 반영하고 `progress.md`에 결정 근거를 기록한다.

## Q1. LLM 모델 확정 (중요)
- 오프라인 PC의 `ollama list` 실제 출력(모델 태그·크기)은 무엇인가요?
- "qwen 3.5 9b"는 공개 배포 태그로 실재가 불명확합니다. 8GB VRAM 안전권인
  **7~8B급 Q4_K_M**(예: `qwen2.5:7b-instruct-q4_K_M`, `qwen3:8b` 계열 Q4) 확정을 권장합니다.
- 원하시는 답변 언어/톤(공식체/간결체) 선호가 있나요?

## Q2. 사내망 다중 사용자 접속 (환경 확인 필요)
- 호스트 PC 방화벽에서 **다른 PC의 접속(인바운드 포트)** 허용이 가능한가요?
- 호스트의 고정 IP 또는 접속 주소, 사용할 포트 지정이 필요한가요?
- 동시 사용자 수는 대략 몇 명을 예상하나요? (동시성/큐잉 설계에 반영)

## Q3. 코퍼스 규모
- 인덱싱 대상 문서 수와 총 용량 대략치는? (청킹·검색 파라미터·재인덱싱 주기 산정)
- 문서가 자주 갱신되나요, 대체로 고정인가요?

## Q4. OCR 방안 (Phase 3)
- 이미지(스크린샷/다이어그램) 비중이 큰가요?
- PaddleOCR(정확도↑, 모델·wheel 대용량) vs Tesseract(엔진 별도 설치) 중 반입 난이도 선호가 있나요?

## Q5. 리랭커 도입 시점
- 초기부터 도입(품질↑, VRAM/지연↑) vs MVP는 하이브리드 검색만으로 가고 품질 부족 시 도입,
  어느 쪽을 원하시나요? (설계 기본값: **MVP 미포함**)

## Q6. HEX 로그 특성
- 로그 파일 크기 범위(수 KB ~ 수십 MB?)와 프로토콜 종류 수는?
- HEX 포맷 예시(텍스트 hex 문자열 / 바이너리 덤프 / 타임스탬프 포함 여부)를 1개 공유 가능한가요?
  (더미 샘플을 실제와 유사하게 만들기 위함 — 실제 데이터가 아니라 형식만)

## Q7. 배포 용량 제약
- USB 배포 폴더의 최대 허용 용량은? (wheelhouse + 모델 크기 예산 산정)

## Q8. 샘플 세트 방향 (다음 단계 게이트)
- 더미 샘플을 만들 때 반영해야 할 실제 자료의 특징(예: 특정 문서 유형이 많다, 표가 매우 크다,
  약어/장비명이 많다 등)이 있나요? — 샘플 생성 전에 미리 알면 검토 반복을 줄일 수 있습니다.
